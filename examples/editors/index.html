Beyond one instance per bundle

Four things a component can be, all attached to the same thing — an editor. Nothing here is configured: what exists is decided by a condition, by a call, and by who is asking.

Everything on screen is read from the loader and the registry. Open the console and try tsm.factories(), tsm.conditions() and tsm.components().

1 · A condition decides when anything starts

A condition is a service with no behaviour — only the statement that something is the case. The toolbars name (condition.id=workspace.ready) and wait; the workspace bundle registers it. Neither knows about the other.

    2 · A factory component: one editor per file

    The Editor class registers no service of its own, only a factory. Each call builds one instance with the properties passed to it — which is the difference from a factory configuration: only the code that opens files knows a file was opened.

      Close the workspace above and the factory is withdrawn: nobody can ask for an instance of a component that cannot run.
